🚀 POUR DÉMARRER (3 ÉTAPES SIMPLES)
═══════════════════════════════════════════════════════════════════

ÉTAPE 1 : INSTALLER ET DÉMARRER MYSQL
--------------------------------------
macOS :
  brew install mysql
  brew services start mysql

Linux :
  sudo apt-get install mysql-server
  sudo service mysql start

Windows :
  Télécharger depuis : https://dev.mysql.com/downloads/


ÉTAPE 2 : CRÉER LA BASE DE DONNÉES
-----------------------------------
Ouvrez un terminal et exécutez :
  mysql -u root -p < database.sql

(Si pas de mot de passe, utilisez : mysql -u root < database.sql)


ÉTAPE 3 : CONFIGURER ET LANCER
-------------------------------
1. Ouvrir src/main/database.ts
2. Modifier le mot de passe MySQL ligne 7
3. Dans le terminal, exécuter :
   npm run dev

L'APPLICATION VA S'OUVRIR AUTOMATIQUEMENT ! 🎉
